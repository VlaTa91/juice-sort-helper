# Помощник переливания колбочек

PWA для уровней со скрытыми слоями `?`. Версия 49 — **экспериментальная**, победа не гарантирована.

## Как пользоваться

1. Откройте PWA и выберите скриншот целого уровня.
2. Сверьте распознанные верхние символы с игрой (особенно розовую колбу №7).
3. Перелейте согласно двум выделенным колбам.
4. Нажмите **«Перелила → дальше»**.
5. Если открылось `?`, укажите новый символ в палитре. Повторные скриншоты не нужны.
6. Когда перезапускаете уровень **в самой игре**, нажмите **«↻ Повтор»** в помощнике: состояние вернётся к началу, а уже раскрытые цвета сохранятся на исходных слоях. Если доступна та же начальная раскладка на новом скриншоте, приложение попытается повторно использовать знания.

Если подсказка не найдена, не переливайте наугад: без отмены ходов ошибка может быть необратимой.

## Решатель

- `scanner.js` — локальное распознавание скриншота. Вынесен дополнительный контроль насыщенно-розового цвета против ошибочной классификации как серого.
- `planner.js` — поиск Монте-Карло по *наблюдаемым* состояниям. Для случайных продолжений используются скрытые раскладки, согласованные с количеством оставшихся фишек каждого цвета. Алгоритм не использует скрытые значения при выборе доступного в игре хода.
- `index.html` — PWA и прежнее управление. После каждого открытия символа стратегия пересчитывается. При полностью открытых колбах используется поисковый решатель.
- `memory.js` — память одной текущей раскладки в localStorage: идентичность каждой фишки сохраняется при переливаниях, обнаруженный цвет привязывается к исходной колбе и исходному слою и подставляется при повторном прохождении. Память сохраняется после закрытия PWA; для другой начальной раскладки она сбрасывается. Совпадение уровней определяется по сохранённой начальной раскладке, не по идентификатору игры.
- `journal.js` — база попыток в IndexedDB: скриншотное начальное состояние, переливания, раскрытия, ручные исправления, завершение или тупик. Активная попытка восстанавливается из localStorage.

Вероятности неизвестных цветов предполагают равномерное перемешивание оставшихся фишек: если генератор игры устроен иначе, оценки могут отличаться от реальных. Сам генератор игры **пока не восстановлен**. Архив накопленных прохождений нужен для будущего исследования.

Экспорт журнала доступен в консоли браузера вызовом `JuiceJournal.exportJson()`; файл называется `История переливаний.json`.

## Автоматические испытания

Запуск: `node "tests/planner tests.js"` и `node "tests/memory tests.js"` — дополнительных пакетов не требуется. GitHub Actions настроен на проверки изменений ядра.

Смоделированы случайные раскладки: 4 слоя на колбу, 2 пустые колбы, нижние три слоя каждого изначально заполненного сосуда скрыты; после каждого переливания открытый символ вводится автоматически в тестовый помощник. Выборка фиксирована seed-значениями.

| Цветов | Успешных полных прохождений | Всего |
| --- | ---: | ---: |
| 3 | 12 | 12 |
| 4 | 20 | 20 |
| 8 | 7 | 10 |
| 10 | 1 | 6 |

Это **результаты симуляций, а не гарантия победы на реальном уровне**. Часть сценариев приводит к необратимому тупику. Реальное распознавание и работа на телефоне не прошли полноценную end-to-end проверку; для неё необходима проверка на устройстве пользователя.

## Ограничения

- Не все скрытые раскладки допускают надёжное прохождение без информации о закрытых цветах.
- Модель предполагает, что каждого цвета ровно 4 фишки и что игра переливает подряд стоящие одинаковые фишки одним действием.
- Сохранение истории само по себе **пока не обучает** генератор; статистическую модель можно доработать на собранных играх.
- История хранится только в браузере на текущем устройстве; для резервного копирования используйте экспорт. Память раскрытых фишек также локальная. Не очищайте данные сайта, если хотите сохранить узнаваемые цвета. Кнопка «↻ Повтор» перезапускает только помощник — игру нужно перезапустить самостоятельно.

Исследованные подходы: POMCP/поиск по информационным состояниям, A* для открытых задач, прикидки через oracle-решатель для полностью известных раскладок. Последний вариант не дал выигрыша на испытаниях и не включён в основной поиск.
